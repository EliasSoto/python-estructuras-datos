# 🐍 Python Estructuras de Datos

> **Repositorio de estudio y práctica de estructuras de datos y algoritmos en Python.**

> [!NOTE]
> *Los ejercicios desarrollados en este repositorio buscan comprender el funcionamiento y la lógica de las distintas estructuras de datos y algoritmos. El objetivo es aprender cómo se comportan y cómo pueden implementarse en Python, priorizando el razonamiento y la comprensión por sobre la eficiencia de la solución.*

---

## 📚 Contenidos

| 📌 Tema                    | 📝 Contenido                                      |
| :------------------------- | :------------------------------------------------ |
| 🟦 `estructuras_basicas`   | Sets, diccionarios, tuplas, strings y excepciones |
| 🟩 `estructuras_dinamicas` | Pilas, colas, listas enlazadas, árboles y grafos  |
| 🟨 `algoritmos`            | Algoritmos de búsqueda y ordenamiento             |
